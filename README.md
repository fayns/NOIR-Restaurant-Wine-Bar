# NOIR — Restaurant & Wine Bar

Modern restaurant landing page built as a frontend portfolio concept.

## ✦ Concept

NOIR is a fictional Copenhagen restaurant focused on seasonal food, natural wine and a relaxed evening atmosphere.

This is a **concept / demo project**, not a website made for a real client.

## ✦ Features

- Responsive layout
- Editorial-style typography
- Animated reveal-on-scroll sections
- Custom cursor on desktop
- Mobile navigation
- Interactive reservation form
- Responsive menu cards
- Reduced-motion support
- Image hover interactions

## ✦ Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## ✦ Run locally

No build tools are required.

Open `index.html` in a browser or use a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## ✦ Portfolio note

The restaurant, text and branding are fictional.
